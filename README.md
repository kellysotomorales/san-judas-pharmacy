# San Judas Pharmacy

Estoy desarrollando el sistema Farmacia San Judas SIG.

Ya conecté mi proyecto de Supabase y tengo creadas las tablas:

- categorias

- productos

- clientes

- ventas

- detalle_ventas

- roles

- usuario_roles

Necesito que revises la estructura existente de mi base de datos y utilices esas tablas para desarrollar la aplicación.

No crees tablas duplicadas ni elimines información.

Primero construye una pantalla donde se muestren los productos registrados en Supabase, incluyendo su código, nombre, categoría, precio, stock y fecha de vencimiento.

Confirma que estás consultando los datos reales de Supabase.
